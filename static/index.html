📖 Справка по интерфейсу

🖱️ Работа с картой

  • Одинарный клик ЛКМ — скрыть панель результатов
  • Двойной клик ЛКМ — поставить точку и найти дорогу
  • Перетаскивание ЛКМ — перемещение карты
  • Колёсико мыши — масштабирование
  • Правый клик + перетаскивание — выделить область для скриншота

⌨️ Горячие клавиши

  • Ctrl+1 — свернуть/развернуть левый фрейм
  • Ctrl+2 — свернуть/развернуть правый фрейм
  • Ctrl+S — запустить режим скриншота вокруг текущей точки
  • Ctrl+L — очистить точку, результаты и буфер копирования
  • Enter — сохранить скриншот (когда выделена область)
  • Esc — отменить выделение / закрыть меню скриншота

🖼️ Панели интерфейса

  • Поиск в правом фрейме — переключатель режимов: адрес, координаты, дорога+км, МСК-61
  • Левый фрейм — загрузка фото, выбранные координаты, история, закладки и пакетная обработка
  • Правый фрейм — поиск, текущий результат дороги и километража; кнопка ⚙️ открывает настройки
  • Панели можно сворачивать стрелками или горячими клавишами Ctrl+1 / Ctrl+2
  • Настройки закрываются кнопкой ×, кликом по фону или клавишей Esc

📸 Загрузка фото

  • Перетащите фото в зону загрузки или кликните для выбора
  • Координаты извлекаются из EXIF автоматически
  • При загрузке нового фото все предыдущие точки и результаты очищаются

📸 Создание скриншотов

  • Правый клик + перетаскивание — выделить область
  • Кнопка «📸 Скриншот» в карточке — запустить скриншот вокруг точки
  • После выделения появится меню сохранения
  • Можно перетаскивать выделение за середину или изменять размер за маркеры

💾 Сохранение файлов

  • В Chrome/Edge — откроется нативное окно «Сохранить как...»
  • В Firefox — файл попадёт в папку «Загрузки»
  • Имя формируется из текста копирования (обрезается до 50 символов с конца)
  • Добавляется временная метка для уникальности
  • Скриншоты старше 7 дней удаляются автоматически

🕒 История точек

  • Хранит последние 10 точек, по которым был поиск
  • Сохраняется в браузере (localStorage)
  • Клик по элементу — мгновенный переход к точке
  • Кнопка «очистить» — удалить всю историю

⭐ Закладки

  • Сохранённые места с именами (хранятся на сервере)
  • Доступны с любого устройства в сети ZeroTier
  • Введите имя → нажмите ➕ (когда есть точка на карте)
  • Клик по закладке — переход к точке
  • Крестик × — удалить закладку

📡 Моё местоположение

  • Кнопка запрашивает координаты через браузерный Geolocation API
  • Мгновенно переносит карту к вам и ставит точку для поиска

🗺️ Контур области

  • Локальный контур — из файла rostov_boundary.geojson, работает мгновенно
  • Overpass API — из интернета, актуальный, но медленный
  • Переключается чекбоксом в настройках (правый фрейм)

🌙 Тёмная тема

  • Применяется только к UI (фреймы, панели, карточки)
  • Карта остаётся светлой для лучшей читаемости
  • Выбор сохраняется в браузере
