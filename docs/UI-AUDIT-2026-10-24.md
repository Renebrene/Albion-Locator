## Рекомендации

### Оптимизация производительности

| Область | Рекомендация |
|---|---|
| Реактивность точек | Хранить `installPointIndex` Map по координатам; при смене фильтра пересчитывать только дельту (add/remove), не `clearLayers` |
| Lazy loading карты | Кэшировать `loadVectorStyle()` (`stylePromise ??= fetch(...)`) |
| Debounce import | Визуальный `.loading` spin на `#installedImportButton` при `button.disabled` |
| Memory | `hideInstalledPoints` не очищать `installedPoints` (500KB / 1544 точек — ок), но при простое >10 мин периодически `installedLoaded = false + installedPoints = []` |

### Архитектурные улучшения

| Область | Рекомендация |
|---|---|
| Фильтры | Вынести в `static/js/filters.js` — класс `InstalledPointFilter`, убрать ~200 строк из inline index.html |
| Состояние фильтров | Хранить в `user_preferences` вместо localStorage — единый source of truth. Синхронизировать с сервером |
| Группировка | Вместо `data-installed-filter="shields"` на каждый input обобщать как `filters: [InstalledPointFilter[]]` с типами `enum` / `range` / `text` |
| Пагинация точек | `GET /api/installed?limit=&offset=&bbox=`; фронт подгружает только видимые |
| Общий sync-движок | Все `applyXxxState` функции — через declarative binding с `SettingsMixin` |
| Сериализация map | `mapSourceApplyChain` скрытую race заменить наabortable queue (`AbortController`) |
