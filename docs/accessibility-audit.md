# Accessibility audit

**Дата:** 19.10.2026  
**Инструмент:** axe-core 4.10.2 в headless Chromium (Playwright), desktop 1440×900, после входа.

## Результат

**0 violations.** До исправлений было 4:
- отсутствовал `main` landmark;
- отсутствовал `h1`;
- часть контента вне landmark-регионов;
- скроллируемый `#help-frame-content` без keyboard-доступа.

## Что исправлено

- `#app-main` получил `role="main"`, левая панель — `complementary`, статус-бар стал `<footer>`, справка — `complementary`.
- Заголовок приложения — `h1`; карточки/секции используют `h2` без пропуска уровней.
- `#help-frame-content` получил `tabindex="0"` и доступное имя.
- Toast — `role="status"`, login overlay — именованный region.
- Ранее добавлены keyboard-доступ для dropzone, меню скриншота, истории, закладок и переключателя темы; focus trap в модалке настроек.
- E2E дополнительно проверяет, что у видимых `button`/`role=button`/`role=switch` и полей ввода есть доступные имена.

## Ограничения

- Автоматический axe-аудит не заменяет ручную проверку screen reader и реальных сценариев.
- Цветовой контраст проверялся только автоматически; для тёмной темы/кастомных состояний нужна отдельная ручная проверка.
