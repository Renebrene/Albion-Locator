# Изменения: 19–20 октября 2026

**Коммиты:** `dc494e6` (QA hardening, vendor assets, RTree) и `e1f59f7` (синхронизация километража, поиск, точка призрака).  
**Ветка:** `feature/ui-variant-a`.

## 1. Поиск и интерфейс

- Единый блок поиска вынесен из левого фрейма: положение **«сверху карты» / «в статус-баре»** переключается в настройках.
- В статус-баре блок стал частью панели (`display: contents`), строка поиска занимает всё свободное место, кнопка 🔍 находится справа.
- Поле поиска прозрачное, без фоновой заливки; в верхнем варианте оно растянуто почти на всю ширину карты.
- По умолчанию активен режим **«Дороги»**; чекбокс поиска при загрузке страницы снят.
- Для дорог работают подсказки по мере ввода (debounce 350 мс), без обязательного нажатия Enter.
- Подсказки в нижнем варианте открываются вверх.
- При положении «сверху карты» управление масштабом переносится в нижний левый угол.
- Убран логотип/префикс Leaflet; обязательная атрибуция OpenStreetMap сохранена.
- Левый и правый фреймы имеют одинаковую ширину (360 px).
- Карточка «Текущая точка» перенесена из правого фрейма в левый.
- Leaflet, его CSS/иконки и `dom-to-image-more` перенесены из CDN в `static/vendor/` и отдаются собственным allowlist-маршрутом. Это устраняет зависимость от блокировщиков/CDN (актуально для Opera и автономных сетей); OSM-тайлы остаются сетевыми.

## 2. Синхронизация точки и официального километража

- Официальный километраж по умолчанию **неактивен**: поле пустое, ползунок disabled, диапазон/статус не показываются. Активация — отдельным чекбоксом рядом с полем.
- После активации синхронизируются:
  - активная точка на карте;
  - ползунок и поле км;
  - блок «Источник СКДФ»;
  - статус-бар.
- Изменение ползунка/поля км двигает точку вдоль геометрии участка СКДФ; фиксация — по `change`, Enter или «Перейти».
- Новая точка автоматически пересчитывает официальный км через проекцию на участки СКДФ.
- Для дороги с кодом участки СКДФ загружаются автоматически (`/api/roads/online/sections`), в том числе для точки, найденной на карте/по адресу/EXIF.
- Блок «Источник СКДФ» больше не скрывается и не пересоздаётся: обновляются стабильные DOM-узлы.
- Убраны дублирующая верхняя надпись «Источник СКДФ» и заголовок «Официальный километраж».
- Мелкие расхождения километража < 50 м между участками считаются стыком, а не разрывом; реальные gaps/overlaps показываются явно.
- Верхнее поле показывает синхронизированные данные активной точки: название трассы, определённый адрес или координаты в выбранной системе (WGS84/МСК-61).

## 3. Точка призрака

- В статус-баре добавлена кнопка 👻.
- При включённых «официальном километраже» и «точке призрака» ползунок/поле км двигают **зелёный клон**, исходная красная точка остаётся на месте.
- «Перейти» удаляет исходную точку, призрак становится красной активной точкой.
- При выключенном призраке ползунок двигает оригинальную точку.
- Призрак удаляется при очистке точки, снятии активации километража или новой точке.

## 4. Режим поиска, фото и пакетная загрузка

- Режим поиска **не блокирует карту**: dblclick по карте ставит точку всегда.
- В режиме поиска блокируются вкладка «Пакетный поиск» и загрузка фото; при необходимости активная вкладка переключается на «Точка».
- После успешной загрузки фото/пакета режим поиска блокируется до нажатия **«Очистить точку»**.
- Если фото уже загружены, чекбокс поиска не активируется.
- «Очистить точку» сбрасывает блокировку.

- Задержка автоскриншота согласована: **1–60 сек**, `delay=0` — 422.
- Исправлено сохранение workspace при очистке точки и reset рабочей сессии.
- Исправлен crop скриншота с учётом координат карты и DPR.

## 6. Offline geo

- Схема `offline_geo` обновлена до **v5**: таблица `road_segments` и `road_segments_rtree`.
- `nearest_road` использует bbox-префильтр RTree, затем точную проекцию.
- Старые индексы schema v4 остаются читаемыми через линейный fallback.
- Benchmark: 20 000 дорог — p50 **421 ms → 0.13 ms** (синтетика). Подробности: `docs/performance-nearest-road.md`.
