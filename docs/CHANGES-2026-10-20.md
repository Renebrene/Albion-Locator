# Изменения: 19–20 октября 2026

**Коммиты:** `dc494e6` (QA hardening, vendor assets, RTree) и `e1f59f7` (синхронизация километража, поиск, точка призрака).  
**Ветка:** `feature/ui-variant-a`.

## 1. Поиск и интерфейс

- Единый блок поиска вынесен из левого фрейма: положение **«сверху карты» / «в статус-баре»** переключается в настройках.
- В статус-баре блок стал частью панели (`display: contents`), строка поиска занимает всё свободное место, кнопка 🔍 находится справа.
- Поле поиска прозрачное, без фоновой заливки; в верхнем варианте оно растянуто почти на всю ширину карты.
- По умолчанию активен режим **«Дороги»**; чекбокс поиска при загрузке страницы снят.
- Для дорог работают подсказки по мере ввода (debounce 350 мс), без обязательного нажатия Enter.
- Подсказки в нижнем варианте открываются вверх.
- При положении «сверху карты» управление масштабом переносится в нижний левый угол.
- Убран логотип/префикс Leaflet; обязательная атрибуция OpenStreetMap сохранена.
- Левый и правый фреймы имеют одинаковую ширину (360 px).
- Карточка «Текущая точка» перенесена из правого фрейма в левый.
- Leaflet, его CSS/иконки и `dom-to-image-more` перенесены из CDN в `static/vendor/` и отдаются собственным allowlist-маршрутом. Это устраняет зависимость от блокировщиков/CDN (актуально для Opera и автономных сетей); OSM-тайлы остаются сетевыми.

## 2. Синхронизация точки и официального километража

- Официальный километраж по умолчанию **неактивен**: поле пустое, ползунок disabled, диапазон/статус не показываются. Активация — отдельным чекбоксом рядом с полем.
- После активации синхронизируются:
  - активная точка на карте;
  - ползунок и поле км;
  - блок «Источник СКДФ»;
  - статус-бар.
- Изменение ползунка/поля км двигает точку вдоль геометрии участка СКДФ; фиксация — по `change`, Enter или «Перейти».
- Новая точка автоматически пересчитывает официальный км через проекцию на участки СКДФ.
- Для дороги с кодом участки СКДФ загружаются автоматически (`/api/roads/online/sections`), в том числе для точки, найденной на карте/по адресу/EXIF.
- Блок «Источник СКДФ» больше не скрывается и не пересоздаётся: обновляются стабильные DOM-узлы.
- Убраны дублирующая верхняя надпись «Источник СКДФ» и заголовок «Официальный километраж».
- Мелкие расхождения километража < 50 м между участками считаются стыком, а не разрывом; реальные gaps/overlaps показываются явно.
- Верхнее поле показывает синхронизированные данные активной точки: название трассы, определённый адрес или координаты. В режиме координат по умолчанию WGS84, доступная зона МСК определяется в фоне; переключатель предлагает только WGS84 и эту МСК, при неверной зоне поле пустое. Координаты призрака показываются в скобках.

## 3. Точка призрака

- В статус-баре добавлена кнопка 👻.
- При включённых «официальном километраже» и «точке призрака» ползунок/поле км двигают **зелёный клон**, исходная красная точка остаётся на месте.
- «Перейти» удаляет исходную точку, призрак становится красной активной точкой.
- При выключенном призраке ползунок двигает оригинальную точку.
- Призрак удаляется при очистке точки, снятии активации километража или новой точке.
- При повторном включении призрак сбрасывается к исходной точке (не сохраняет прежнее смещение).
- Карточка «Текущая точка» показывает активный призрак: WGS84, МСК и источник «Точка призрака (предпросмотр)». После выключения призрака карточка возвращается к основной точке. Сохранение закладки для призрака заблокировано до «Перейти».
- Название из источника СКДФ убрано из правого фрейма и выводится слева в статус-баре; в правом фрейме под «Из справочника» остаётся справочное название дороги.
- Стрелки клавиатуры двигают ползунок только после фокуса в поле км, Tab-фокуса/клика по ползунку или клика по нужному маркеру: по зелёному призраку при включённом призраке, иначе — по красной точке.
- Добавлен дискретный шаг ползунка 5/10/50/100/500 м: кнопка с числом в статус-баре циклически переключает шаг, такой же селектор вынесен в настройки. Под ползунком рисуются вертикальные штрихи выбранного шага и точки каждые 1000 м; на длинных трассах используется локальная шкала вокруг бегунка.
- В настройках появились переключатели клавиатурного управления ползунком и управления колесом мыши (при фокусе в поле км или на ползунке).
- Добавлено слежение за ползунком: кнопка 👁 в статус-баре и чекбокс в настройках. При движении ползунка или вводе километража карта следует за точкой (или призраком), сохраняя масштаб. Пока режим активен, карта не управляется клавиатурой — только ЛКМ. Кнопка «Перейти» центрирует карту на выбранном километраже и фиксирует точку. Режим работает только при активном официальном километраже.

## 4. Режим поиска, фото и пакетная загрузка

- Режим поиска **не блокирует карту**: dblclick по карте ставит точку всегда.
- В режиме поиска блокируются вкладка «Пакетный поиск» и загрузка фото; при необходимости активная вкладка переключается на «Точка».
- После успешной загрузки фото/пакета режим поиска блокируется до нажатия **«Очистить точку»**.
- Если фото уже загружены, чекбокс поиска не активируется.
- «Очистить точку» сбрасывает блокировку.
- В пакетном режиме поиск недоступен, новые точки по карте не ставятся: правый фрейм работает с пакетной точкой, выбранной кликом по маркеру или строке списка; её можно двигать ползунком официального километража.
- Кнопка центрирования приближает карту к активной точке (zoom ≥16), а для нескольких пакетных точек использует `fitBounds` с maxZoom 16.

## 9. Исправления логики синхронизации

- Выбор дороги в онлайн-поиске теперь готовит точку и при выключенном официальном километраже: используется ближайший километр СКДФ или координата дороги. Ранее 🔍 повторно запускала поиск подсказок.
- «Очистить точку» очищает строку поиска, все черновики (адрес, координаты, дорога), отложенные таймеры и состояние призрака. Старая точка больше не может быть возвращена кнопкой поиска.
- Кнопка «Поставить точку» в панели МСК переведена на общий `commitPoint()`: обновляются карточка, статус-бар, история и workspace.
- `commitPoint()` больше не проецирует новую точку на ранее загруженную дорогу: ползунок только отображает ближайший км, а сама точка не смещается до подтверждения кода дороги. Синхронизация ползунка с точкой также больше не двигает точку.
- Ползунок в пакетном режиме обновляет координаты пакетной точки, её маркер и строку списка, а не только скрытую активную копию.
- Очистка пакетного списка снимает блокировку поиска, если не осталось одиночного фото; удаление активной пакетной точки очищает правый фрейм и режим редактирования.
- Призрак выключается вместе с удалением маркера; кнопка 👻 больше не остаётся нажатой без призрака.
- В режиме МСК Enter использует текущее содержимое поля X/Y, а не устаревший черновик; при переходе границы зоны выбранная доступная МСК следует за точкой. Подпись и aria-поля меняются на МСК-61.
- Клавиатура и колесо мыши фиксируют километр после паузы, как отпускание ползунка; отложенный ввод км отменяется при смене точки/дороги.
- Повторное нажатие на активный режим поиска не очищает черновик; стрелки вкладок пропускают disabled-вкладки; кнопка переключения систем не разблокируется в обход режима поиска.
- Задержка автоскриншота приведена к backend-диапазону **1–60 сек**; устранена гонка инициализации Yandex SuggestView и наложение таймеров toast.
- Для дорог без официальных участков СКДФ (например, `60К-31`) добавлен fallback по OSM Overpass: `/api/roads/overpass/geometry` собирает связанные way в приблизительную ось, UI рисует оранжевую пунктирную линию и включает относительную шкалу `0…длина`. Клик по линии выбирает километр и ставит точку; данные явно помечены как приблизительные.
