# Изменения 24.10.2026

Продолжение `docs/CHANGES-2026-10-20.md`. Ниже — что появилось после аудита 22.10.2026.

## Вход, пользователи, безопасность

- Форма входа приведена к ТЗ: «АЛЬБИОН.Локатор / закрытый веб-сервис / вход по логину и паролю / их можно получить у Администратора». Предзаполнение и подсказка `админ/альбион` убраны.
- Кнопка 👤 в статус-баре: окно пользователя — логин, роль, смена своего логина/пароля, выход.
- `must_change_password`: после bootstrap и после сброса пароля администратором включается принудительная смена пароля (окно нельзя закрыть, остальные API отвечают 403).
- `ALBION_COOKIE_SECURE=auto|always|never`; `Secure` включается по HTTPS/`X-Forwarded-Proto`.
- CSRF double-submit (`albion_csrf` + `X-CSRF-Token`) и Origin-проверка для всех изменяющих `/api/*`.
- Rate-limit `/api/*`, отдельный лимит входов и lockout после 5 неудач; параметры настраиваются.
- Security headers: CSP, HSTS на HTTPS, X-Frame-Options DENY, nosniff, Referrer/Permissions Policy, `frame-ancestors 'none'`.
- `/docs`, `/redoc`, `/openapi.json` закрыты (`ALBION_ENABLE_DOCS=1` для разработки).

## Наблюдаемость и аудит

- JSON-логи в journald: `request_id`, метод, путь, статус, длительность, пользователь, upstream-поля.
- `GET /metrics` — Prometheus-текст: HTTP, upstream, ретраи, кэш, аудит; loopback или `ALBION_METRICS_TOKEN`.
- `audit_log` + `GET /api/audit` + «Журнал событий» в настройках: входы, неудачные попытки, смена данных, действия админа, импорт XLS.
- Retry/backoff и TTL-кэш для WFS, Overpass и Yandex (`ALBION_UPSTREAM_RETRY_ATTEMPTS`, `ALBION_UPSTREAM_CACHE_TTL`).

## Установленные точки из таблиц

- Импорт `.xls`/`.xlsx`/`.ods` в настройках администратора: только город, адрес, сторона, формат конструкции и координаты.
- XLS/XLSX конвертируются в ODS через headless LibreOffice; разбор устойчив к битому `styles.xml`, поддерживает отдельные колонки широты/долготы и повторный импорт без дублей.
- Разбор сериализован (`threading.Lock`) и ограничен таймаутом 150 c (504 при зависании).
- Зелёный слой точек на карте, группировка по координатам/адресу, переключатель «Скрыть/Показать точки».
- Фильтры: только щиты («Щит» и «Биг-борд»), только районы кроме Ростова-на-Дону, только трассы (название, код дороги, километраж, положение вне города). Комбинируются, сохраняются в персональных preferences, дублируются в настройках.
- Кэш точек инвалидируется между вкладками/устройствами по `count`/`updated_at` и `visibilitychange`.

## Офлайн-данные и эксплуатация

- Локальная векторная подложка (MapLibre) и растровые MBTiles; при установленных локальных тайлах карта предпочитает их OSM онлайн, при 403 от OSM автоматически переключается на локальный слой.
- `deploy/backup_data.py` — backup `users.db` и офлайн-данных с `manifest.json`, SHA-256 и `PRAGMA integrity_check`; шаблон systemd-таймера.
- `deploy/update_offline_data.py` — сборка индекса и MBTiles в staging, проверки, rollback и атомарная замена, manifest с версией.
- `deploy/nginx/albion-locator.conf` — шаблон LAN-reverse-proxy с TLS; `deploy/security_check.py` — preflight `.env` и ключей.
- Проверено, что CloudPub передаёт `X-Forwarded-Proto: https`, реальные `Host`/`X-Forwarded-For`/`X-Real-IP` и перезаписывает подменённые forwarding-заголовки.
