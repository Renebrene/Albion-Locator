# Live-проверка Yandex и СКДФ WFS

**Дата:** 19.10.2026  
**Среда:** изолированный uvicorn на временной SQLite-БД, реальные ключи из локального `.env`; пользовательские данные рабочей БД не затрагивались.

## Результаты

| Проверка | Результат | Время |
|---|---|---:|
| `/api/maps-config` | `suggest_view_available=true`, `geocoder_available=true` | — |
| `POST /api/roads/online/search` (`М-4 Дон`) | `200`, найдено `М-4`, precision `street` | 358 ms |
| `POST /api/roads/online/sections` (`М-4`) | `200`, диапазон `826.3–1154.5 км`, 647 участков | 2072 ms |
| `POST /api/address/online/geocode` (`Ростов-на-Дону, Большая Садовая 1`) | `200`, координаты `47.217855, 39.696085`, precision `exact` | 230 ms |

## Замечания

- Это проверка доступности провайдеров и контракта, а не гарантия квот/стабильности конкретного deployment.
- Адресный текст и координаты уходят внешнему провайдеру; для production нужны политика приватности и ограничение ключей по домену.
- WFS-запрос участков занял ~2 s; UI должен показывать загрузку и не блокировать остальные действия.
- Ключи не выводились в отчёт и не сохранялись в артефактах.
